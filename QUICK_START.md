# 🚀 QUICK START - Deploy Your Portfolio NOW!

Everything is ready! Just follow these 3 simple steps:

## 📋 STEP 1: Create GitHub Repository (2 minutes)

1. Open: https://github.com/new
2. Repository name: **`portfolio`**
3. Make it **PUBLIC**
4. Click **"Create repository"**
5. Copy the repository URL

## 💻 STEP 2: Run These Commands (1 minute)

```bash
cd c:\Users\mohan\my-react-app

# Replace the URL with your actual repository URL
git remote add origin https://github.com/Nisith116/portfolio.git
git branch -M main
git push -u origin main
```

## 🌐 STEP 3: Deploy to GitHub Pages (1 minute)

```bash
npm run deploy
```

## 🆘 Need Help?

**If you get an error about the remote already existing:**
```bash
git remote remove origin
git remote add origin https://github.com/Nisith116/portfolio.git
git push -u origin main
```

**If GitHub Pages isn't showing:**
1. Go to your repo Settings → Pages
2. Select `gh-pages` branch as source
3. Wait 2-3 minutes
